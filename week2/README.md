# Week 2 – Provider-Agnostic LLM Client

## Aim
The aim of this experiment was to create a common LLM client that can work with both Google Gemini and a locally running Ollama model. I wanted to understand how different AI models can be used through a single application.

## Technologies Used
- Python
- Google Gemini API
- Ollama (Llama 3.2)
- Requests
- Python-dotenv
- Unittest

## Files Used
- `llm_client.py` – Contains the code for connecting with different LLM providers.
- `main.py` – Used to run the application.
- `test_client.py` – Used to check whether the code is working correctly.
- `requirements.txt` – Contains the required Python libraries.
- `.env` – Used to store the API key.

## How I Executed It

1. First, I created the required Python files for the project.
2. I installed all the required libraries using the command:

   ```bash
   pip install -r requirements.txt
   ```

3. I added my Google Gemini API key to the `.env` file.
4. I also used Ollama with the Llama 3.2 model to try running an LLM locally.
5. After setting everything up, I started the application using:

   ```bash
   python main.py
   ```

6. The application asked me to choose between Gemini and Ollama.
7. I selected a provider, entered a prompt and checked the response generated by the model.

## Testing

To check whether the application was working properly, I executed the unit test using:

```bash
python -m unittest test_client -v
```

The test was successful, and I also got a response from the local Ollama Llama 3.2 model.

## What I Understood

Through this experiment, I understood that we don't always have to write separate application logic for every AI model. We can create a common interface and connect different LLM providers through it.

I also learned the difference between using an online model like Google Gemini and running a model locally using Ollama. I understood how API keys are stored using a `.env` file and how unit testing helps us check whether our code is working correctly.

One thing I found interesting was that I could switch between Gemini and Ollama without changing the entire application.

## Result

I successfully created and executed the common LLM client. I was able to test the application, select different providers and get responses from the model. The unit test also passed.

## Conclusion

This experiment helped me understand how different AI models can be connected to one application. I also got practical experience with Python, APIs, local LLMs and unit testing.
