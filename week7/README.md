\## Experiment Details



The input prompt used was:



`Artificial intelligence is`



The tokenizer converted the prompt into four token IDs:



`\[8001, 9542, 4430, 318]`



The model generated logits with the shape `(1, 4, 50257)`.



Softmax was applied to the logits to convert them into probabilities. The `torch.topk()` function was used to identify the five most probable next-token candidates.



\## Observed Results



| Rank | Candidate Token | Probability |

|---|---|---:|

| 1 | a | 16.4362% |

| 2 | the | 6.6132% |

| 3 | not | 4.8673% |

| 4 | one | 3.6778% |

| 5 | an | 3.5226% |



The most probable next token was \*\*"a"\*\*.



\## What I Understood



\- A language model produces logits for the possible next tokens.

\- Logits are raw scores and are not probabilities.

\- Softmax converts logits into probability values.

\- Top-k sampling identifies the k candidates with the highest probabilities.

\- The model predicts the next token based on the given input context.

\- The probabilities of the top five candidates do not necessarily add up to 100%.
